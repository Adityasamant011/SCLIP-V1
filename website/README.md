# SCLIP Beta Website

The official beta launch landing page for **SCLIP V1** (The Agentic AI Desktop Video Editor).

## 🚀 Instant Deployment Options

### Option 1: GitHub Pages (Free, Zero Config)
1. In your GitHub repository (`Adityasamant011/SCLIP-V1`), go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/website` (or configure via GitHub Actions).
4. Save, and your site is live at `https://adityasamant011.github.io/SCLIP-V1/`!

### Option 2: Vercel (1-Click)
```bash
cd website
npx vercel
```

### Option 3: Netlify / Cloudflare Pages
* Root directory: `website/`
* Build command: *(leave empty)*
* Publish directory: `.`

- **Precision Typography:** Pairings of *Plus Jakarta Sans* (display) and *JetBrains Mono* (timecodes/MCP calls).
