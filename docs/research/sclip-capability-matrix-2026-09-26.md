## 3. Critical Architectural Constraints & Invariants

### 1. Authoritative State Single-Writer Rule
There is **only one timeline writer**: `apps/desktop/src/main/state/actor.ts` (`createActor`). Neither the Hermes agent nor the React UI ever mutates state directly. Every edit — whether dragging a clip in the UI or an agent executing `ripple_delete_layers` — compiles into a command dispatched through `actor.command()` or `actor.mcpCall()`.

### 2. Zero Shadow State
There is **no secondary or shadow timeline**. The agent reads state via `get_timeline_context` or `actor.snapshot()` and writes state via `ActorHandle`. Every mutation immediately reflects in the UI timeline view and is recorded in the project's linear undo history.

### 3. Explicit Export Boundary
AI agents are **strictly prohibited** from performing final project exports. The `export_timeline` tool is removed from the advertised MCP catalog. Agents can only generate temporary QA preview clips (`render_timeline_range`) or query frame snapshots (`inspect_timeline_frame`). Final video rendering and delivery remains under explicit human editorial control.
