# 0086: Native media turns, shared resources and scoped evidence

Status: accepted implementation; creator-run live performance/quality acceptance pending

Sclip uses Hermes as the sole foreground creative agent and ProjectActor as the sole timeline writer. Repeated discovery, serial preparation, terminal-driven continuation and duplicate observation/render work delayed actual edits. This change adapts the harness without introducing a second planner or host-selected creative decisions.

Native plugin hooks carry accepted prompt/turn identity and completion policy over the authenticated loopback lifecycle endpoint. The supported generic `pre_completion` extension has an actual Sclip plugin consumer. It permits at most two same-turn continuations for specific missing review and then reports incomplete. PTY output/readiness is display-only. Native stop/cancel, source/state/creator/opening checks and existing write authority remain binding. The Hermes source revision and dependencies stay pinned; five explicit source patches are hashed in its runtime manifests.

A small stable authorized editing core is visible directly. Specialist schemas remain deferred, with bounded six-schema discovery. Only exact authorized MCP tools that also declare read-only metadata can overlap through deferred calls. Writes remain barriers. Existing operator/plugin opt-outs, bounded read allowlists and optional specialist authorization are rollout controls; rollback is a complete retained application snapshot, never a second active orchestrator or mutation replay.

A shared scheduler admits local-model, audio-CPU, FFmpeg and network work. Foreground work can preempt owned idle inference, but the resource is retained until the process/request actually settles. Queues, result stores and coalescing are bounded and scoped. Asset preparation holds native authority independently of an individual HTTP response and returns handles without import or placement. Cancellation/close discard late results. Timing diagnostics contain only bounded IDs/model/timing/token metadata.

Evidence observations reuse only after dependency validation, with project opening, model/config identity, actual source file identity, animated curves, settings and nested mappings in the key. They create a current acquisition response; an old review receipt never becomes current merely by replacing its version. Opaque Motif render dependencies disable range reuse; pixel-identical local inference can still reuse its exact-question result. Completion reuses an already valid exact-state decode proof. Current background/live concerns are deduplicated and retain uncertainty. Optional Jev advice now reads current cached rendered-mix speech; missing evidence means skip, not source-transcript fallback.

Revising ADR 0085, nested `CompositionRef` paired provenance follows native child-to-root offsets and each clip's source speed. Facts and sampled composed observations do not certify aesthetic/factual correspondence. Output-boundary count sizes finite review acquisition budgets; source count sizes finite discovery budgets, while separate authored-content budgets remain bounded. Budgets do not select edits or reset after arbitrary mutations.

The existing atomic repair transaction adds typed track/layer/graphic creation, deletion, placement and parameter-track changes. Preceding `@ref` identities resolve within one validated draft and one undo unit. Bounded request receipts reconcile exact retries in the current actor/opening; they do not promise exactly-once behavior across a crash.

HyperFrames keeps its existing self-contained HTML/SVG/GSAP and Motif manifest/four prop types. Scene intent is optional descriptive metadata. Approved imported stills and explicit local fonts embed into immutable source within strict byte limits; remote loading stays disabled. Fonts/images settle before capture, and 2–4 chosen preview times can be requested together. Motion examples are composable techniques, not a mandatory design/template pipeline or quality judge.

Revising ADR 0082, attributed prompts/manual corrections/reactions remain canonical evidence, interpreted only by the foreground agent. Relevant bounded learning context is available in an ordinary turn; a separate automatic post-delivery learning turn is removed. Current user instructions and creator controls outrank inferred patterns. General Hermes factual memory remains separate; automatic generic curation does not become a second creator-style store.

No model/provider defaults, optional remote authorization, paid service, existing project or approved preference changes are implied. Windows inference and full-length music generation are not added. Engineering checks cover contracts/types and native hook compatibility without provider calls. The user explicitly owns live media/speed/creative acceptance; no new benchmark claim is made before those runs.
