# Editorial evidence is observational; verification follows declared modalities

A review model changed video to address a speech cut and marked the issue resolved after visual inspection, while audio was unchanged. Sparse-frame pooled perception also erased variation. These are evidence/verification failures, separate from editorial judgment.

## Decision

Hermes starts with a bounded observation index through its existing skill preload. The authenticated current-project endpoint and MCP packet tool reuse ProjectActor, transcript cache and timeline context. The initial receipt survives review reconnects; state hashes identify snapshots. The index includes actual A/V source relationships, cached word projections for both audio and video, text, technical intervals and available current visual observations. Unobserved perception and truncated sections are explicit. Targeted range requests/deeper tools expand the index. No provider/model default changes.

Hermes declares observable issue dimensions: visual, audio, speech, text, geometry and timeline. Multimodal claims list each dimension. Receipts expose supported dimensions, actual coverage and state identity. A flat issue can close only after fresh current-timeline receipts cover every declared dimension in its area. Source transcripts can supplement diagnosis but cannot alone verify the changed composition. Video-source cues do not establish edited audible speech; the packet observes Audio mappings with cached word timing. The infrastructure records whether the relevant evidence was acquired, never whether the edit improved. Hermes can finish unresolved, choose another justified action, or conclude no repair.

A/V relationship changes are observable notes, including candidate relationships disappearing/appearing. Intentional offsets remain valid; infrastructure never changes a paired layer automatically. Automatic repair suggestions from the legacy background advisory are not appended to mutation results.

Representative visual samples are observed individually through the existing local perception engine, bounded to 2–5 requests. A labelled list preserves contradictions; there is no pooled unanimous verdict. Pixel/question/model cache reuse is bounded; changed pixels are reobserved. Current-state range indexes invalidate after editorial state changes.

## Limits

Transcription and visual perception can be inaccurate. The packet is an index, not the whole project; initial visual perception may be unavailable until explicitly requested. No semantic audio model, calibrated face detector, creative score, judge model, tracking, crop algorithm or prescribed repair is introduced. Legacy RoughCutReview remains a state-level compatibility path; modality claims use flat declared issues.
