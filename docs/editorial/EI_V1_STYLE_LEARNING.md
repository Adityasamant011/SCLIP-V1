Synthetic Alpha and Beta only; real creator stores untouched. Persistent disposable profile locator in ignored `style-study/profile-location.json`. Every native run uses a new project; trial setup is an explicit two-second caption fixture, not editorial moment selection. No expected font value was supplied to the three initial native label prompts.

This establishes useful storage, authentic capture and bounded isolation, **not positive autonomous canonical learning**. The missing step is the native hypothesis action backed by actual evidence IDs and fresh creator/revision bindings. Hermes retains freedom to abstain; a future experiment should make this legal route easier to discover without forcing a candidate or a universal28px rule. Once a real tentative candidate exists, evaluate application on unseen footage, contradictory corrections, scoped exceptions and current overrides. Caption-only study does not certify pacing/framing/intro/transition/audio preference generalization.
