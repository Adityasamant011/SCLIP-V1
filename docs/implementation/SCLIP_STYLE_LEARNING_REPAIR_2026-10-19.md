evidence alongside actual manual edits and corrections. Agent layer and structural

such as restoring dialogue after an AI mute are associated with the actual changed
property; unrelated manual changes do not become false AI corrections. Adjacency
and matching values still do not establish the creator's reason.

lifecycle hook. `creator_style_memory` can page relevant retained observations
across projects, including observations previously reviewed as ambiguous. The
foreground agent synthesizes concise conditional style patterns or supported
mistake-prevention lessons, with applicability, rationale, evidence, exceptions and
counterexamples. Example measurements remain evidence, not universal settings.
Creator approval, disabling, forgetting, isolation and current-request priority
remain intact. No deterministic averaging or confidence promotion was added.

A considered observation receives a review outcome. `learned` requires a successful
current evidence-linked preference write, including valid current claims beyond
the three retained capsule samples. Otherwise the agent can record insufficient,
project-specific, technical-repair or non-style evidence. No fake preference is
required to finish a review. Reviewed facts remain available for later patterns.

Normally completed chat turns can request at most one learning continuation when
actionable evidence is still pending. It uses the same conversation, yields to
delivery review and newer user input, and permits at most twelve canonical MCP
memory calls. Host admission rejects other tools in this pass; the native hook
also rejects generic memory/skill writes and external work. No separate background
model was enabled. General Hermes memory and skills remain available in ordinary
turns. The old caption-clustering provider remains bypassed.
